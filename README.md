# 여백 — Android 소설 뷰어

TXT와 EPUB 파일을 기기에서 열어 읽는 독립 Android 앱입니다. 파일 내용은 앱에서 로컬로 처리합니다.

## 포함 기능

- Android 파일 선택기에서 TXT와 EPUB 열기
- TXT 인코딩 자동 판별: UTF-8, EUC-KR, UTF-16
- EPUB 목차와 본문 순서 읽기
- 최근 책, 읽던 장과 스크롤 위치 저장
- 책갈피, 글자 크기, 줄 간격, 본문 너비 조절
- 종이, 세피아, 야간 화면과 앱 화면 밝기 조절
- GitHub Actions에서 debug APK 자동 빌드

## APK 받기

GitHub 저장소에서 Actions → Build Android APK → 최근 성공한 실행을 열고 `yeobaek-reader-debug-apk`를 다운로드하면 됩니다. 압축을 풀어 APK를 설치하세요.
